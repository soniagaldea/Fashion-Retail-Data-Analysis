# Dataset

This project uses the **Global Fashion Retail Sales** dataset available on Kaggle.

The dataset contains synthetic transactional data representing two years of sales activity for a multinational fashion retailer.

Due to GitHub file size limitations, the dataset is not included directly in this repository.

To run the analysis:
1. Download the dataset from Kaggle.
2. Extract the CSV files.
3. Place all CSV files inside this `data/` directory.

**Source:** [Global Fashion Retail Sales - Kaggle] https://www.kaggle.com/datasets/ricgomes/global-fashion-retail-stores-dataset
